# DeskDash

Небольшая настольная панель на ESP32 с цветным TFT-экраном. Показывает **инфо-панель**
(загрузка CPU/RAM, температуры, диски, сеть, часы/дата) и проигрывает **гифки/картинки**.
Данные о ПК передаются с компьютера на экран — по USB-кабелю (COM) или по Wi-Fi.

Проект сделан «по максимуму»: двухъядерный ESP32 + IPS-экран 240×240.

| Микроконтроллер | ESP32 dual-core (2 ядра, 30-pin) | 171 ₽ |

## Архитектура

```
[ПК: deskdash_pc.py] --(USB serial / Wi-Fi)--> [ESP32] --(SPI)--> [ST7789 240×240]
   psutil: CPU/RAM/                              прошивка:
   temps/net/time                                TFT_eSPI + LVGL + AnimatedGIF
```

ESP32 также может работать автономно (часы, гифки) без ПК.

## План работ

1. Скелет проекта и README — *готово*.
2. ПК-скрипт: сбор статистики и отправка на ESP32 (начать с этого — не требует железа).
3. Прошивка ESP32: драйвер ST7789, отрисовка панели, проигрывание гифок.
4. Связка ПК ↔ ESP32 (USB-сериал, опционально Wi-Fi).
5. Сборка, припайка пинов, проверка на живом железе.

> Точные пины (SPI: SCK/MOSI/CS/DC/RST/BL) и формат обмена зафиксируем после заказа — уточним перед написанием кода.
