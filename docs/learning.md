# Учебные заметки DeskDash

## 1. Как устроен новый ПК-скрипт

Файл `pc/deskdash_pc.py` разделён на небольшие части:

- настройки `UPDATE_SECONDS` и `BAR_LENGTH` лежат сверху, чтобы их было легко менять;
- `ComputerStats` описывает, какие показатели собирает программа;
- `collect_stats()` получает CPU, RAM и занятость диска через `psutil`;
- `make_bar()` превращает процент в текстовую полоску;
- `show_panel()` отвечает только за вывод панели;
- `main()` запускает повторение обновлений.

Такое разделение похоже на набор отдельных инструментов: каждый делает одну понятную работу, а `main()` соединяет их в общий процесс.

## 2. Новые понятия

### Функция

Функция — это именованный мини-инструмент. Например, `collect_stats()` умеет собирать показатели, а `make_bar()` умеет строить полоску. Функцию можно вызвать несколько раз и не дублировать её внутренний код.

### Словарь

`ComputerStats` описывает словарь с парами «имя показателя → значение». Например, `cpu_percent` хранит загрузку процессора. Это удобно, потому что данные можно передавать между функциями одной группой.

### Цикл

`while True` повторяет сбор и показ данных. Остановить бесконечный цикл можно сочетанием `Ctrl+C`.

### Типизация

`float`, `str` и `ComputerStats` подсказывают, какие данные ожидает функция. Python не требует их для запуска, но человеку и редактору проще понять код.
