# Пайка для новичка — чек-лист под наш проект

Задача: припаять **штырьковые разъёмы (pin headers)** к плате ESP32 и к модулю экрана
ST7789. Соединять ESP32 и экран напрямую друг к другу не нужно — потом свяжем проводами
Dupont (мама-папа).

> Первый раз паяешь? Прочитай раздел «Как паять один контакт» дважды. Главное — не спешить.

---

## 0. Перед началом — подготовка

- [ ] Проветрить комнату (дым от флюса)
- [ ] Застелить поверхность доска / силиконовый коврик
- [ ] Приготовить: подставку, губку/латунную стружку, припой, флюс, кусачки, пинцет, очки
- [ ] Подготовить макетную плату (breadboard) — она держит гребёнку ровно
- [ ] Убрать со стола всё лишнее, ничего не класть на подставку с паяльником

## 1. Безопасность

- [ ] Помнить: жало нагрето до ~300–400 °C — проверять только глазами, не пальцем
- [ ] Паяльник кладём ТОЛЬКО на подставку
- [ ] Работать в очках (припой может «плюнуть»)
- [ ] Не вдыхать дым — работаем с наклоном и проветриванием

## 2. Паяльник (ROYDEN 80 Вт, без регулировки)

- [ ] Включить заранее, дать прогреться **3–5 минут** (не 30 секунд!)
- [ ] **Залудить жало**: покрыть кончик тонким слоем блестящего припоя
- [ ] После каждых нескольких паек: вытереть жало о губку и снова чуть подлудить

## 3. Припой и флюс

- [ ] Припой лучше **свинцовый (Sn63/Pb37)**, 0.6–0.8 мм, с канифолью внутри — проще всего для старта
- [ ] Отдельный флюс (ЛТИ-120 или гелевый) — мажем каплю в место пайки, припой «прилипает» сам

## 4. Как паять один контакт (ГЛАВНОЕ ПРАВИЛО)

1. [ ] Приложить жало **одновременно к пину и к площадке** → прогрев **1–2 сек**
2. [ ] Поднести **припой** к месту (не к жалу) — он расплавится и обтечёт контакт
3. [ ] Убрать **сначала припой**, через секунду — **жало**
4. [ ] Не двигать и не дуть **2–3 сек**, пока припой застывает

**Хорошая пайка:** блестящая, гладкая, маленькая «горка».
**Холодная (плохая):** мутная, серо-матовая, шариком → добавь флюс, прогрей ещё раз.

**Нельзя:**
- [ ] Держать жало дольше ~3 сек (отклеиваются площадки)
- [ ] Лишком много припоя (мост между пинами)
- [ ] Недостаточно прогреть (холодная пайка, нет контакта)

## 5. Припайка гребёнки — пошагово (для каждой платы)

- [ ] Втыкнуть гребёнку в breadboard: **длинные штырьки вниз, короткие вверх**
- [ ] Надеть плату отверстиями на короткие штырьки
- [ ] Припаять **первый угловой пин**
- [ ] Проверить: плата ровно, без перекоса (поправить — перепаять угол)
- [ ] Припаять **противоположный угол** (диагональ) — конструкция держится
- [ ] Ещё раз проверить ровность
- [ ] Припаять **все остальные** пины

Порядок: сначала **ESP32**, потом **экран ST7789** (у него ряд ~8 пинов: GND, VCC, SCL, SDA, RES, DC, CS, BLK).

## 6. После пайки

- [ ] Прозвонить мультиметром соседние пины — **не должно быть короткого** (мостов)
- [ ] Если мост: прогреть и убрать лишнее, либо тесьмой-оплёткой (solder wick)
- [ ] Промыть от флюса изопропиловым спиртом + щётка (не обязательно, но чище)
- [ ] Осмотреть под ярким светом: все контакты блестящие и гладкие

## 7. Первая тренировка

- [ ] До платы потренироваться: припаять пару проводов к ненужной плате/гребёнке
- [ ] Понять «на ощупь»: сколько держать жало, как течёт припой
- [ ] После ~5–10 контактов переходить на настоящие платы

---

## Быстрая шпаргалка «что не так»

| Симптом | Причина | Что делать |
|---|---|---|
| Припой шариком, не прилипает | не прогрет / нет флюса | добавить флюс, прогреть 2–3 сек |
| Матовая серая пайка | мало прогрева | прогреть, чуть добавить припоя |
| Мост между пинами | лишний припой | убрать оплёткой/жёгой, прогреть |
| Площадка отклеилась | слишком долго грел | не спасать, использовать соседний/провод |
| Дым и вонь | сгорает флюс | нормально, проветривать |
