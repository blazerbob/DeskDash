## Заметки для кода

- Драйвер экрана: **ST7789**, разрешение **240×240**, шина **SPI**.
- Библиотеки (Arduino C++): `TFT_eSPI` (драйвер) + `LVGL` (панель) + `AnimatedGIF`
  (воспроизведение гифок; совместима с `TFT_eSPI` на ESP32).
- Питание и уровни: 3.3 В (логика ESP32 совпадает с TFT-модулем).
- Пины SPI (SCK/MOSI/CS/DC/RST/BL) — зафиксируем при сборке; в `TFT_eSPI` их задают
  в файле `User_Setup.h`.
